Questions

Before you ask.

Who owns my data?

You do. Your records stay yours and can be exported whenever you want, including if you leave.

Do I need my own IT staff or servers?

No. We host, back up, update and support everything. You only need a browser.

How long does a build take?

Ready-made systems take days to set up. Custom builds are delivered feature by feature, so you're using real parts of it within weeks, not months.

What if the price changes halfway?

It doesn't. Scope and price are fixed before we start. New ideas you have along the way are quoted separately, and only if you want them.

How do you make sure it actually works?

Every system passes nine checks before it goes live, including testing by someone who has never seen the code and a separate security review. How we work →

Home / About

Most software ships on hope. Ours ships on checks.

Tercet AI Innovations Inc. is a Philippine software and AI company. We build systems for businesses that can't afford wrong totals, lost records or a vendor who disappears.

Our approach

Why we exist

Anyone can generate an app now. Few companies will prove it works and stand behind it. That's the part we do: we build the system, test it until it holds, then stay around to run it.

Nothing is “done” until it's run

We don't call a feature finished because the code is written. It's done when it has been used end to end, as each kind of user, and passed. If something hasn't been tested, we tell you so.
